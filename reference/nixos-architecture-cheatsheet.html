NixOS Multi-Device Architecture Cheat Sheet

📁 Repository Layout & Seams

  • modules/core/base.nix: Universal baseline (Users, SSH, Locale, Flakes).
  • modules/profiles/*.nix: Functional roles (server.nix, desktop.nix).
  • modules/services/*.nix: Deep reusable services (Self-registering Caddy).
  • hosts/<host>/configuration.nix: Declarative host manifest.
  • hosts/<host>/persistence.nix: Centralized state paths for impermanence.

🔒 Ephemeral Storage Rules

  • Never put environment.persistence in service modules.
  • Mount persistent filesystems with neededForBoot = true;.
  • Mount large data pools with options = ["nofail" "x-systemd.after=zfs-import.target"];.
  • Wipe root in boot.initrd.postDeviceCommands = lib.mkAfter "zfs rollback -r ...";.

🌐 Self-Registering Service Pattern

# Inside modules/services/my-service.nix:
services.caddy.virtualHosts."${cfg.subdomain}.${caddyCfg.domain}" =
  lib.mkIf caddyCfg.enable {
    extraConfig = ''
      tls internal
      reverse_proxy localhost:${toString cfg.port}
    '';
  };

🚀 Verification Checklist

  • Code formatting: nix fmt (Alejandra)
  • Evaluation: nix eval .#nixosConfigurations.<host>...
  • Deployment: ./deploy.sh <host>
  • Cold Reboot: systemctl reboot to test rollback and mounts.
  • Status: systemctl list-units --failed
