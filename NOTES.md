# Teaching Notes & Preferences

- **Core interest:** Architectural trade-offs — not just *how* a mechanism works, but *why* this design was chosen over alternatives, what breaks under each alternative, and where the trust/complexity boundaries sit.
- **Grounding:** Anchor every lesson in real components running in this repository (`homelab` microVM orbs, ZFS, NixOS modules, `ADR-0005` / `ADR-0006`).
- **Format:** Self-contained Tufte-style HTML lessons in `./lessons/` backed by reusable components in `./assets/` and printable references in `./reference/`. Open lessons in `firefox`.
- **Style:** High signal, zero fluff (per `MISSION.md`). Short lessons that fit in working memory, paired with retrieval practice.
