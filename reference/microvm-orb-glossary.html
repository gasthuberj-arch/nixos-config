MicroVM Orb Storage & FUSE Glossary

Compressed reference for the storage and isolation primitives in ADR-0005 & ADR-0006.

Core Terms

FUSE (Filesystem in Userspace)
A Linux kernel mechanism that delegates filesystem syscalls (open, read, write, stat) from the kernel to a regular userspace daemon rather than an in-kernel filesystem driver. Stateful: the kernel and daemon share numeric nodeids and open file handles. (kernel docs)
virtiofs
A paravirtualized shared filesystem for VMs built on the FUSE protocol. Instead of passing FUSE messages over local /dev/fuse, the guest kernel sends them over shared-memory virtqueues to a host daemon (virtiofsd). (kernel docs)
virtiofsd
The host-side Rust userspace FUSE server that receives guest virtiofs requests and performs real syscalls against an exported host directory. Supports --sandbox=namespace (isolated root via pivot_root), chroot, or none. (virtiofsd repo)
ZFS Filesystem Dataset vs. ZVOL
A filesystem dataset (zfs create rpool/orbs/id) is a POSIX directory tree with dynamic recordsize; the host mounts and inspects it directly. A ZVOL (zfs create -V 20G ...) is a raw block device (/dev/zvol/...) with fixed volblocksize, typically attached to a VM via virtio-blk where the guest formats its own ext4/xfs. (OpenZFS docs)
DEVICE_STATE / virtiofsd Migration
The protocol required to snapshot or live-migrate a VM using virtiofs: virtiofsd must serialize its in-memory table of guest-opened inodes (via find-paths or file-handles) so a restored VM's cached FUSE handles remain valid. (migration.md)
tmpfs Overlay
A RAM-only filesystem mounted either as an overlayfs upper layer (/nix/store over read-only /nix/.ro-store) or directly over a sensitive subdirectory (/home/user/.gemini) so writes never reach persistent host storage.
AF_VSOCK & CID
A Linux socket address family for direct VM-to-host communication without Ethernet, IP, or firewalls. Addresses consist of a 32-bit Context Identifier (CID) plus a 32-bit port number. (vsock(7))
Hybrid vsock (Cloud Hypervisor / Firecracker)
Exposes standard AF_VSOCK inside the guest while presenting a plain AF_UNIX socket on the host (notify.vsock). Host clients select a guest port by sending CONNECT <port>\n before streaming data, using standard Unix file permissions instead of host kernel vhost_vsock. (CH vsock.md)
systemd-ssh-proxy & systemd-ssh-generator
Systemd v256+ helpers for out-of-band SSH. systemd-ssh-proxy handles vsock-mux/<unix-socket> via ProxyCommand + ProxyUseFdpass=yes (passing the connected fd directly to ssh). systemd-ssh-generator auto-binds vsock:22 inside VMs unless disabled with systemd.ssh_auto=no. (systemd docs)
TAP Device & Bridge (tap-orbN / br-agent)
A virtual Layer-2 Ethernet interface exposed to a userspace VMM (cloud-hypervisor). Each orb slot attaches its TAP (multi_queue) to the host bridge br-agent (10.240.0.1/24). (tuntap docs)
nftables Base Chain & Final Drop
Netfilter runs every table's base chains registered on a hook (input, forward, postrouting) in ascending priority order. A drop verdict in any table is final, so table inet agent-isolation cannot be weakened by another firewall table. (nftables wiki)
